## Upgrading from 0.8

**Projects open by their project file.** A project is still its folder, but its
file is now `project.wcpr` (it was `project.json`), and a pack is a `.wcpk`.
**Open project…**, on the start screen and in the File menu, picks either one:
a `.wcpr` opens its project, a `.wcpk` is unpacked into a new folder you
choose. Projects in your Recent list open as before.

**Double-click a `.wcpr` or `.wcpk` to open it in WeftCut**, on Windows, macOS
and Linux. Installing or updating to 0.9 registers both types; the AppImage
registers them the first time it runs.

**A 0.8 project can no longer be opened by 0.8 once 0.9 opens it**, even
without an edit: its `project.json` is renamed to `project.wcpr`. To keep using
a project in 0.8, copy its folder before opening it here. The original stays
beside it as `project.pre-v7.json`. To open a 0.8 project that is not in Recent,
pick *WeftCut 0.8 project (project.json)* in the Open project dialog.
