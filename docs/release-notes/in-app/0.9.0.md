- Projects now have their own file types: open a project by its `.wcpr` file,
  or a packed project by its `.wcpk`. For a project from 0.8, pick its
  `project.json` in Open project; it moves to the new format as it opens (0.8
  cannot open it after that, so keep a copy if you still need 0.8).
- A project folder now holds everything the project uses, Motifs and fonts
  included. Copy or pack the folder and it plays the same on any computer.
- Motifs that come from someone else's project wait for your trust before they
  run, so you can check what you open before it plays.
- Transitions between linked clips now crossfade their sound too.
- **Q** and **W** trim a clip's start or end to the playhead in one key.
- Plus many bug fixes.
