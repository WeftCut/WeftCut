## Good to know

- **Projects open by their project file**, `project.wcpr`. Once 0.9 opens a
  0.8 project, 0.8 can no longer open it. Copy the folder first if you still
  need 0.8.
- **Motifs live in the project.** Each project keeps its own copy under
  `Motifs/`, so it plays the same on another computer.
- **A Motif from elsewhere waits for your trust.** It shows *Not trusted*
  until you select it and press **Trust**.

## New

- **File → Pack project…** puts a project into one `.wcpk` file to move or
  share it.
- **Audio crossfades** come with transitions between linked clips.
- **Q** and **W** delete a clip's start or end up to the playhead.
