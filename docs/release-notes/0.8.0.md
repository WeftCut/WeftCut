## Upgrading from 0.7

**Reconnect your agents.** WeftCut now ships its own `weftcut` program for
agent connections, and the stdio connection that 0.7 set up (a
`weftcut-mcp.cjs` script started through the app) no longer works: an agent
using it gets a one-line message saying so. Open **Settings → Agent** and copy
the new connection (or the setup prompt) into each agent, once. It stays valid
across later updates. An agent connected over HTTP directly (a URL and a token)
is not affected.

- Claude Code: remove the old entry first (`claude mcp remove weftcut -s user`),
  then add the new one; the panel's command does both.
- Scripts that read `get_mcp_info`: `cli_path` replaces `exe_path`,
  `appimage`, `user_data` and `shim_path`.

**Canvas snapping.** Hold ⌘ on macOS (Ctrl on Windows and Linux) to move
without snapping, the same key the timeline uses. macOS used Ctrl before.

Projects are unchanged: 0.7 and 0.8 open each other's projects.

## What's new

- **Side preview**: agents can open a read-only page that mirrors the editor
  (`open_side_preview`), with the live picture when you turn it on.
- **Where you are**: agents can read the playhead, the marked range and the
  selection (`project://playhead`), so "this part" means what you see.
- **Canvas grid** and a canvas snapping toggle in the preview.
- **Timeline**: the snap target is shown while dragging, and every time mark
  (playhead, blade, guides) shares one look.
- **Status bar**: one log line, one work pill (background exports show their
  progress there) and a notification bell.
- **Preview during export** (beta, off by default).
- **Saving**: a project that keeps failing to save says so, and quitting asks
  before losing edits. `project.json` is replaced atomically.
- **macOS**: signed with Developer ID and notarized by Apple.
