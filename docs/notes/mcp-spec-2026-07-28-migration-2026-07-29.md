# MCP 2026-07-28 / TypeScript SDK v2 migration assessment — 2026-07-29

Not started; the app is on `@modelcontextprotocol/sdk` ^1.x. Re-check versions
before acting.

## Findings

- **No runtime blocker**: SDK v2 needs Node ≥ 20; the repo requires ≥ 22.
- **Installing v2 does not enable the modern protocol.** A hand-built v2
  `Client`/`Server` still negotiates the legacy era unless it uses the modern
  HTTP handler (`createMcpHandler`) or explicit version negotiation
  (`versionNegotiation: { mode: "auto" }` or a `2026-07-28` pin on clients).
- **Hono gate**: `@modelcontextprotocol/node@2.0.0` declared
  `@hono/node-server ^1.19.9`, while GHSA-frvp-7c67-39w9 affects every version
  below 2.0.5. Either a temporary root override to `^2.0.5` (upstream verified
  `getRequestListener` works on 2.x; typescript-sdk PR 2549) with a full
  regression run, or wait for an adapter patch.
- **What changes for WeftCut**: no `initialize` or protocol sessions (no
  `Mcp-Session-Id`, every POST self-describing); discovery via
  `server/discover`; request/result `_meta`; results carry `resultType` and
  cache hints; no GET event stream, `Last-Event-ID` or resource subscribe; a
  missing resource is `-32602` (WeftCut currently returns method-not-found);
  every supplied `Origin` must be validated (`403`), where WeftCut deliberately
  leaves Origin unrestricted today.
- **Change feed has no core equivalent**: the unsolicited
  `notifications/weftcut/change` maps to `subscriptions/listen` +
  `resourceUpdated("project://current")`; the compact summary would need a
  negotiated extension, off by default.

## Recommended shape

A dual-era `/mcp`: bearer auth and Host/Origin checks first, then
`isLegacyRequest` routes to the existing sessionful handler, everything else
to `toNodeHandler(createMcpHandler(factory, { legacy: "reject" }))`. A missing
Origin stays valid for non-browser clients. Host shutdown must release legacy
transports and modern streams. Retire the legacy path only after measuring
client adoption, never as part of the package bump.

## Touch points

`main/mcp/index.ts` (session map, Host check, change broadcast),
`main/mcp/server.ts` (v1 schema-first `setRequestHandler`, plain-`Error` codes →
v2 `ProtocolError`), `state/resource-views.ts` error mapping,
`electron.vite.config.ts` externals (only `@modelcontextprotocol/sdk` today —
verify packaged ESM subpaths), the Electron E2E specs that import the v1
client, `scripts/mcp_probe.py`, `docs/mcp.md`, and the lockfile (Zod 3 + 4
copies).
