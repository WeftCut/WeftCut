# Craft

Production rules that hold for every WeftCut job, whatever the style: numbers
and thresholds (how long a title stays on screen, how far text sits from the
frame edge, how long an audio fade runs) and named anti-patterns (a default
that makes an edit look generic, with what to do instead).

Each file here covers one topic. Read the ones that touch the job before you
plan it, and check your result against them before you hand off. When this
folder holds only this file, no craft rules apply beyond what the tools
themselves enforce.

## How the rules bind

- A rule is a number or a threshold. Meet it; do not reinterpret it.
- A style the user chose may tighten a number (a longer minimum hold, a wider
  margin). It never loosens one.
- The user's explicit request may override a rule. Do what they asked, and in
  your report name the rule you departed from and by how much.
- An anti-pattern names a default to avoid. When your plan heads for one,
  change the plan.
