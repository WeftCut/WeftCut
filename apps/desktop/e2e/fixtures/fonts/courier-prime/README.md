# Courier Prime (e2e fixture)

The installed font of `e2e/electron/project-fonts.spec.ts`: a family that is
not bundled and that the specs install by pointing `WEFTCUT_E2E_FONT_DIRS` at a
folder holding these files. Monospaced, so a line in it measures unlike the
same line in any bundled fallback.
